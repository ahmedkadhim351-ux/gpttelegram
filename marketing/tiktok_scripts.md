# TikTok-сценарии для продвижения GPT-Telegram-бота

Готовые сценарии коротких роликов (15–30 сек) для официального
аккаунта бота. Структура каждого сценария:

* **Хук (0–3 сек)** — фраза/действие, которое не даст пролистать.
* **Демо (3–25 сек)** — экран Telegram, реальная фича в действии.
* **CTA (25–30 сек)** — призыв к действию + ссылка на бота.
* **Подпись + хэштеги** — для описания под видео.

> Имя бота указано как `@your_bot` — замените на реальный username
> перед записью.

---

## 1. «ChatGPT прямо в Telegram, без VPN»

**Целевая аудитория:** русскоязычные, у кого ChatGPT-сайт не открывается.

* **Хук:** Текст на экране «ChatGPT не работает? Открой Telegram».
* **Демо:** Открываете чат с ботом, пишете типичный запрос
  («объясни как 5-летнему, что такое RAG»), бот моментально отвечает
  оформленным сообщением.
* **CTA:** «Бесплатно. Ссылка в шапке профиля → @your_bot».
* **Подпись:** «GPT-4o прямо в Telegram, без VPN и регистрации.»
* **Хэштеги:** `#чатгпт #нейросети #ии #телеграм #лайфхак #чатгптнарусском`

## 2. «Голосом — ответ текстом» (Whisper)

**Цель:** показать фичу транскрипции голосовых.

* **Хук:** «Лень печатать? Запиши голосовое.»
* **Демо:** Записываете голосовое в чат с ботом
  («помоги написать поздравление маме на день рождения»). Бот
  присылает транскрипт + готовое поздравление.
* **CTA:** «Голосовые, кружочки, аудио — всё распознаёт.»
* **Подпись:** «Whisper + GPT-4o = твой голосовой ассистент.»
* **Хэштеги:** `#голосовоесообщение #ai #нейросеть #продуктивность #телеграм`

## 10. «5 фишек, которые ты не знал»

**Хорошая «зонтичная» идея, можно повторять каждые 2 недели с
новыми фишками.**

* **Хук:** «5 фишек этого Telegram-бота за 30 секунд».
* **Демо:** Быстрая нарезка — каждая по 4-5 секунд:
  1. Текст в чат → ответ GPT.
  2. `/image` → картинка.
  3. Голосовое → расшифровка.
  4. `/model` → выбор модели.
  5. `/reset` → новый чистый диалог.
* **CTA:** «Сохраняй пост — пригодится. @your_bot».
* **Подпись:** «5 вещей, которые умеет этот Telegram-бот с GPT.»
* **Хэштеги:** `#лайфхак #телеграм #нейросеть #ai #продуктивность`

## Чек-лист перед публикацией

* Видео вертикальное **9:16**, длительность 15–30 сек.
* Первые **3 секунды без логотипа и долгих интро** — иначе
  пролистывают.
* Подпись 80–150 символов, имя бота **в самом начале**, чтобы было
  видно до кнопки «ещё».
* 4–6 хэштегов: 1–2 широких (`#ai`, `#нейросеть`), 2–3 нишевых
  (`#чатгпт`, `#telegram`), 1 трендовый (смотри в TikTok Creator
  Center → Insights).
* Звук — желательно из тренда (TikTok Creator Center → Sounds →
  Trending). Это даёт буст в раздаче.
* Постинг **в одно и то же время каждый день** (например, 19:00
  МСК) — алгоритм быстрее «понимает» аккаунт.

## Как использовать с автопостингом

После того как ты получил `access_token` (см.
`tiktok_autopost/README.md`), публиковать готовое видео можно
одной командой:

```bash
python -m tiktok_autopost post path/to/video.mp4 \
  --title "GPT-4o прямо в Telegram. Бот в шапке профиля → @your_bot" \
  --privacy SELF_ONLY
```

`SELF_ONLY` — стартовый режим для теста: видео загрузится только
для тебя, чтобы убедиться, что всё хорошо. После этого меняй на
`PUBLIC_TO_EVERYONE`.
